# Yawn project instructions

Before building, signing, notarizing, installing, uploading, deploying, or
retiring a Yawn release, read [DEPLOYMENT.md](./DEPLOYMENT.md).

Use [docs/distribution-runbook.md](./docs/distribution-runbook.md) for the
detailed evidence record and native packaging background. Do not treat a source
commit, a local DMG, or an Apple acceptance alone as a public release.
